# Security Policy

## Supported version

Security fixes target the latest version on the `main` branch while DesignShelf
is in active MVP development.

## Reporting a vulnerability

Please do not publish sensitive security or privacy findings in a public issue.
Use GitHub's private vulnerability reporting for this repository when
available, or contact the maintainer through the public profile contact
information.

Include:

- A clear description of the issue
- Steps to reproduce it
- The affected browser and operating system
- The potential impact
- A suggested fix, if known

DesignShelf is local-first, but imported JSON and external URLs should still be
treated as untrusted input.
