# Code of Conduct

DesignShelf is an open project for thoughtful, respectful collaboration.

Participants are expected to:

- Discuss ideas and code without personal attacks
- Give specific, constructive feedback
- Respect differences in experience, identity, and perspective
- Avoid harassment, threats, discrimination, and unwanted attention
- Protect private information shared during security or support discussions

Maintainers may edit or remove abusive content and restrict participation when
needed to keep the project safe and productive.

Report conduct concerns privately through the maintainer's GitHub profile
contact information. Reports will be reviewed as promptly and confidentially
as practical.
