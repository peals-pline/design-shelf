# Changelog

All notable changes to DesignShelf will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project intends to follow semantic versioning as it matures.

## [Unreleased]

### Planned

- Narrow-screen layout improvements
- Safer JSON import preview and validation
- Automated tests for domain and export logic

## [0.1.3] - 2026-06-07

### Changed

- Connected native form controls to their visible labels and helper messages.
- Added accessible invalid states and moved focus to the first invalid field.
- Added accessibility regression coverage to CI.

## [0.1.2] - 2026-06-07

### Changed

- Tightened the dashboard hero, action area, and metric cards on tablet and
  mobile widths so the first screen feels intentional instead of stretched.

## [0.1.1] - 2026-06-07

### Changed

- Polished the mobile topbar so search, navigation, and the primary Add action
  occupy stable rows.
- Replaced visible command shortcut copy with a platform-neutral `Ctrl K` label.

## [0.1.0] - 2026-06-07

### Added

- Local-first design library dashboard
- Fonts, palettes, UI references, copy snippets, design systems, inspiration,
  and project kits
- Search, filters, tags, favorites, and sorting
- Palette CSS and design-token exports
- Project kit Markdown brief export
- JSON backup and import
- Demo data and interface customization
