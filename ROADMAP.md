# Roadmap

DesignShelf is released as a usable local-first MVP. The roadmap prioritizes
reliability and data safety before broadening the feature set.

## v0.1 - Open-source MVP

- Searchable local design library
- Seven supported item types
- Tags, filters, favorites, and sorting
- Project kits and Markdown brief export
- Palette CSS and design-token exports
- JSON backup and import
- Demo data and theme controls

## v0.2 - Reliability and accessibility

- Fix narrow-screen overflow and improve mobile navigation
- Improve form labels, focus management, and keyboard behavior
- Add import preview and merge/replace controls
- Validate backup shape and surface useful import errors
- Add tests for domain and export logic

## v0.3 - Durable local storage

- Add an IndexedDB storage adapter
- Migrate existing browser data without loss
- Support larger libraries and image metadata
- Add recovery guidance and backup reminders

## v0.4 - Modern toolchain

- Move to Vite and TypeScript
- Add schema validation for all item types
- Add browser-level smoke tests
- Keep the current interface and interaction model intact

## Later

- Image attachments and drag-and-drop
- Duplicate URL detection
- Collection-level import and export
- Optional File System Access API backup
- PWA offline installation
- Optional Figma metadata import
